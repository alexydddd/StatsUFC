# StatsUFC
Base de données Oracle sur l'UFC : combattants, événements, combats et arbitres.
Projet personnel réalisé avec SQL Developer pour m'entraîner a SQL.

## Contenu de la base

- CATEGORIE_POIDS : catégories de poids (mouches, légers, etc.)
- COMBATTANT : identité, pays, taille, catégorie
- EVENEMENT : nom, date, ville, salle
- COMBAT : les deux combattants, le vainqueur, la méthode, le round de fin
- ARBITRE : arbitre de chaque combat

## Logiciels utilisés

- LOOPING : pour modéliser le MCD de ma base de données
- SQL Developer : pour créer ma base de données
